# CyberMP

Welcome to the CyberMP issue tracker. Please note that this repository is dedicated solely to managing bug reports and feature requests—it does not contain the actual CyberMP source code.

## Reporting a Bug

Think you've discovered a glitch or technical issue? Here is how to let us know:

1. **Search first:** Before creating a new ticket, please browse the [open bug reports](https://github.com/cyber-mp/cybermp-issues/issues?q=is%3Aissue+state%3Aopen+label%3Abug) to see if another user has already documented the problem. It is also worth checking the [closed issues](https://www.google.com/search?q=https://github.com/cyber-mp/cybermp-issues/issues%3Fq%3Dis%253Aissue%2Bis%253Aclosed%2Blabel%253Abug) to see if a fix has already been rolled out.
2. **Submit your report:** If your issue is entirely new, [open a new bug report](https://github.com/cyber-mp/cybermp-issues/issues/new/choose) and select the appropriate template.
3. **Be specific:** It is vital that you provide clear steps to reproduce the bug, along with your current client version and any relevant logs.
4. **Follow the template:** Submissions that ignore the template or lack actionable information (like reproduction steps) may be delayed or closed without resolution.

## Suggesting a Feature

We are always looking for ways to improve the CyberMP experience and welcome your ideas.

1. **Avoid duplicates:** Take a quick look through the [current feature requests](https://github.com/cyber-mp/cybermp-issues/issues?q=is%3Aissue+state%3Aopen+label%3Aenhancement) to make sure your idea hasn't already been suggested or planned.
2. **Share your idea:** If your concept is completely new, [open a feature request](https://github.com/cyber-mp/cybermp-issues/issues/new/choose) using the provided template. Be as detailed as possible about how the feature would work and why it would benefit the community.

## Need Support?

If you are struggling to reproduce a bug, aren't sure if something is actually broken, or just need general troubleshooting assistance, GitHub is not the best place to ask.

Instead, head over to our official [CyberMP Discord server](https://discord.cyber.mp) where our community and support team can help you isolate the problem.
